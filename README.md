# ПАНЕЛЬ — день первый

Пошаговая RPG от первого лица о ядерной зиме в российском панельном микрорайоне.
Браузер, Babylon.js, без единого внешнего ассета: текстуры, снег и звук генерируются
в рантайме, поэтому сборке нечего ломать и нечего скачивать.

> Один обычный день. Один обычный человек. Потом свет гаснет, и оказывается,
> что ты умеешь гораздо меньше, чем думал.

## Что это сейчас

Играбельный вертикальный срез «День первый» — от 15 до 30 минут:

- **пять персонажей вместо классов**: фельдшер, программист, учитель, мама в декрете,
  сантехник. Разница не в цифрах урона, а в том, какие двери открываются;
- **четыре локации**: квартира на девятом, подъезд с настоящей лестницей на все девять
  этажей и выходом во двор, двор с четырьмя типовыми панельками (5, 7 и 9 этажей)
  и разграбленный магазин;
- **пошаговый бой, который не выкидывает из первого лица**: мир замирает,
  у тебя два очка действия, ход исполняется одновременно с ходом врага;
- **выживание**: тепло, еда, вода, рассудок, силы. На улице −27, в квартире +9,
  и разница между ними — это и есть геймплей;
- **сохранение**: прогресс пишется в localStorage на каждом переходе и на каждом сюжетном флаге,
  на титульном экране появляется «продолжить». Финал сохранение стирает;
- **два решения с последствиями**: сосед с третьего в подъезде и человек у полки в магазине.
  Можно отдать еду, можно соврать, можно ударить первым.

## Запуск

```bash
npm install
npm run dev        # http://127.0.0.1:5173
npm run build      # сборка в dist/
npm run preview    # посмотреть собранное
```

| Клавиша | Действие |
| --- | --- |
| W A S D | идти |
| Shift | быстрее |

| E | взаимодействие |

В бою — кнопки внизу экрана, каждое действие стоит одно очко из двух.

## Публикация на GitHub Pages

Сборка уже настроена: `.github/workflows/deploy.yml` собирает проект и публикует `dist`.
В настройках репозитория остаётся включить **Settings → Pages → Source: GitHub Actions**.
`vite.config.ts` использует `base: './'`, поэтому сайт работает и в корне домена,
и по адресу `/<имя-репозитория>/`.

## Как устроено

```
src/core/     симуляция: часы, температура, тело, предметы, инвентарь, ГПСЧ.
              Ни одного импорта Babylon — поэтому её можно тестировать и переносить.
src/render/   Babylon: процедурные текстуры, туман, снег, пост-обработка,
              конструктор локаций из коробок и простая AABB-коллизия.
src/game/     состояние игры, контроллер от первого лица, пошаговый бой.
src/ui/       DOM поверх канваса: HUD, выбор персонажа, диалоги, рюкзак, финал.
src/content/  персонажи и весь сценарий первого дня.
scripts/      shot.mjs — снимки через Chrome DevTools Protocol, smoke.js — прогон сюжета.
```

Три решения, которые стоит знать, если будешь читать код:

1. **Симуляция не знает о рендере.** `src/core` — чистые данные и формулы, время
   идёт через `Clock`, случайность — через детерминированный ГПСЧ.
2. **Всё серое сделано шумом.** `textures.ts` рисует бетон, обои, линолеум и снег
   на canvas; фасад панельки строится под конкретный дом — сетка «секция × этаж»,
   поэтому окна, балконы и шахта подъезда стоят друг над другом, а не плывут из-за тайлинга.
3. **Коллизия — прямоугольники.** Никакого физического движка: круг игрока против
   набора AABB со скольжением вдоль стен, лестница — наклонный объём.
